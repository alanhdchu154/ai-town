# Research Episode Packages

Research packages connect papers to Underworld implementation and findings.

Each package should contain:

- `paper_brief.md`
- `underworld_connection.md`
- `script.md`
- `references.md`
- `visual_suggestions.md`
- `upload_metadata.json`
- `review.md`

Required structure:
1. What the paper claims.
2. How Underworld implemented or explored it.
3. Results.
4. Failures.
5. Future work.

Do not claim that a paper proves Underworld works.
