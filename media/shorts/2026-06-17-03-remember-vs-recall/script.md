# Script

What would it mean for an AI character to forget?

At first, I thought memory was simple:
save the text, retrieve the text.

But people do not remember that way.

Sometimes a memory exists,
but nothing in the present reaches it.

So in Underworld, I started separating two things:
the memory itself,
and the cue that lets a character actively recall it.

That cue might be an embedding,
a person,
a place,
or the same emotional situation appearing again.

Forgetting does not have to mean deleting the memory.

It can mean the memory sinks deeper,
until only the right person,
the right room,
or the right kind of hurt
brings it back.
