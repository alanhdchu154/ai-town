# Script

We finally closed one of the most important loops in my AI world.

For a while, Underworld worked like this:

something happened,
a character talked,
the conversation became memory.

But that was still one-way.

If you said something kind to a character,
the world could remember the sentence,
but the character's state did not really move forward.

So the missing edge was:

conversation changes emotion,
and emotion changes the next conversation.

Not as a number.
Not "happy plus five."

More like:
Umi gets warmer,
Mahiru gets more worried,
someone becomes guarded,
someone starts saying less.

This is not sentience.
It is a functional affective loop.

But it matters because the goal of Underworld is not "AI characters talk."

The goal is:
you come back tomorrow,
and something from yesterday is still quietly there.
