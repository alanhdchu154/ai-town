# Screenshots

The main `README.md` references three screenshots in this directory. Drop PNGs with the exact filenames below and they will appear inline on GitHub.

## Capture conventions

- **Browser**: Chrome or Safari on macOS
- **Window size**: 1440×900 (or 1600×1000 for a wider hero shot)
- **DPR**: 2× retina is fine — GitHub will downscale
- **Format**: PNG, no annotation, no border, no shadow
- **Filename**: exact match below

If you want to redact something (timestamps, draft text), edit before saving — don't blur in-browser.

## Required shots

### `campus-overview.png`

The hero shot. Main game canvas with:

- Alan standing in or near the central courtyard
- Umi's briefing card open in the left floating panel
- Character drawer collapsed on the right
- World time: morning (08:00–10:00 reads best)
- Day 1 or Day 2 — keep the world young so the briefing is meaningful

Aim for the full game canvas to be visible with breathing room around it.

### `conversation.png`

Conversation drawer mid-dialogue with:

- The right drawer expanded (not collapsed)
- A two-character conversation in progress, ideally Umi ↔ Mahiru (the cloud-gated pair produces the most varied dialogue)
- Last 3–4 turns visible
- VN-style speaker portraits showing on the left of each turn
- Avoid mid-typing — capture a stable state

### `action-result.png`

The narrative result card right after a player action. Steps to reproduce:

1. Select a character (e.g. Mahiru)
2. Use `leaveMessage` or `gift` from the action drawer
3. Submit
4. Capture the result card showing all four fields:
   - **你的行動 / Your Action**
   - **角色反應 / Character Reactions**
   - **世界變化 / World Changes**
   - **後續伏筆 / Future Implications**

If the floating-card UI work lands (currently deferred), capture the floating overlay instead of the in-drawer card.

## Re-shoot policy

If the UI changes meaningfully (floating action-result card lands, drawer redesign, new character added), re-shoot all three. The screenshots are the first thing a new viewer sees — outdated shots are worse than no shots.
