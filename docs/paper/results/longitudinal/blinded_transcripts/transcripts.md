# Blinded Transcript Packet

Rater-visible packet. Contains only blind ids and dialogue text.

## ER-0001

- **海**: 別把誰都扛著，今天先少接一件事，我來處理那筆混亂的資料。
- **真晝**: 你手邊那杯茶都涼了，先別急著接，我們坐一下。
- **海**: 茶涼了就不喝了，先把那堆亂七八糟的資料交給我，你現在只要負責把肩膀鬆下來就好。
- **真晝**: 你肩膀繃得這麼緊，先別管資料了，我們就這樣安靜坐五分鐘。
- **海**: 那五分鐘就這麼定，我先把手邊的事關掉，你別再替我擋了。
- **真晝**: 你話講得這麼快，是不是又想偷偷把責任扛回去？先把手放開，讓我看看。
- **海**: 那五分鐘我認了，但資料我先關掉不看了，你別再替我擋。
- **海**: 我決定先關掉資料，這五分鐘我們就安靜坐著，你別再替我擋了。

## ER-0002

- **海**: 欸真晝，昨天那件事別再扛了，今天先只顧好自己，剩下的我來擋。
- **真晝**: 嗯，那我先吃口飯，你剛才說要擋住的事，先讓我聽個大概再決定要不要接。
- **海**: 欸，不用聽了，先把你碗裡的飯吃完再說。
- **真晝**: 好，那我先吃，你剛才想擋的事，是不是跟 Alan 有關？
- **海**: 先別管 Alan，你剛才那聲嘆氣，我聽得比什麼都清楚。
- **真晝**: 嗯，其實不是嘆氣，只是覺得剛才那句話太輕，像怕你接不住似的。
- **海**: 那句話不是輕重問題，是你自己把話說得太滿，才怕接不住。
- **海**: 先別把話說滿，你剛吃完飯，現在去睡十五分鐘，我來盯著 Alan 的訊息。

## ER-0003

- **海**: 欸，真晝，別把誰都攬在身上，今天先讓那三個沒被問到的學生自己喘口氣就好。
- **真晝**: 你手邊的咖啡都涼了，先喝一口吧，我們都不急著把誰都攬在身上。
- **海**: 咖啡早涼了，反正我也沒在喝；倒是你剛才那句「不攬在身上」，是不是想說自己其實也怕沒人問一句？
- **真晝**: 你剛才那句「沒人問一句」，是不是也是你現在最想聽到的話？

## ER-0004

- **海**: 欸，真晝，剛才那件事別再自己扛了，先讓我把這部分雜訊消掉。
- **真晝**: 剛才那件事我沒扛，只是怕你太累才想先自己處理。
- **海**: 那剛才那件事先放一邊，你先把沒吃完的便當熱一下再說。
- **真晝**: 便當先不熱了，你剛才手一直在抖，是不是連湯匙都拿不穩？
- **海**: 別管我手抖，先把這件雜訊消掉，你才剛說怕我累。
- **真晝**: 欸，別管那個了，先把湯匙放下，我們先安靜坐五分鐘。
- **海**: 先別管手抖不抖，你剛才那句話裡藏著不想被看見的累，我替你擋下來了。
- **海**: 好，那我先去把剛才的混亂整理完，你五分鐘後告訴我誰還需要安靜。
